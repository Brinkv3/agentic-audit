# Statement of Work — Acme Corp Data Audit

## Engagement Overview

Carter Brinkley Consulting LLC will conduct a data audit for Acme Corp, focusing on the enterprise data landscape across core business applications. The engagement will assess data flows, integration patterns, data quality practices, governance posture, and alignment with Acme's target-state lakehouse architecture.

## Scope

### Applications in Scope
- Payroll System (custom, integrated with Workday and SAP)
- CRM Platform (Salesforce, integrated with Marketo and NetSuite)
- Customer Support Portal (custom, integrated with Salesforce)
- Financial Reporting (SAP, receiving data from multiple systems)

### Assessment Areas
1. **Data Sources and Flows** — map where data originates, how it moves, and where it lands
2. **Integration Patterns** — assess API vs. batch vs. file-based integrations across the application portfolio
3. **Data Quality** — evaluate validation rules, quality controls, and monitoring in place
4. **Dependencies** — map critical data dependencies and assess failure impact
5. **Governance** — evaluate data ownership, PII handling, and compliance posture
6. **Target State Alignment** — assess how current state aligns with Acme's lakehouse-centric target architecture

## Deliverables
1. Interview question framework tailored to Acme's application portfolio
2. Completed interview findings organized by application
3. Data flow and dependency mapping
4. Gap analysis with prioritized recommendations
5. Executive summary presentation

## Timeline
- Week 1-2: Question framework development and initial interviews
- Week 3-4: Remaining interviews and analysis
- Week 5: Synthesis and deliverable development
- Week 6: Presentation and handoff

## Constraints
- All interviews must be conducted with both the business owner and a technical representative
- Findings must distinguish between documented facts and anecdotal information
- Recommendations must align with Acme's stated lakehouse architecture direction
